# Pi Theory

Pi Theory is a speculative research program about whether the mathematical structure associated with pi can illuminate a more general grammar of manifestation, organization, scale, life, consciousness, and symbolic cognition.

The project begins with a simple mathematical relation:

```text
pi = circumference / diameter
```

This relation connects circular measure to straight diametral measure. Pi is exact and invariant for Euclidean circles, while its positional expansion is non-terminating and non-repeating.

Pi Theory asks whether that combination - exact structure, circular closure, finite measure, and inexhaustible representation - can serve as a disciplined starting point for a broader model of reality.

## Current kernel

The exploratory decoding program stabilized the following sequence:

```text
M -> BIEN -> GIHECEF -> JNON -> B0UM -> SIZE
```

The current abstract reading is:

```text
cohesion -> orientation -> differentiation -> integration -> transition -> scale
```

This sequence is not treated as established physics. The original decoding was exploratory, not preregistered. Pi Theory does not impose one validation method on every layer: metaphysical claims are assessed through conceptual coherence and comparative structural convergence; historical claims through primary-source scholarship; statistical decoding claims through controls and prospective procedures; and physical claims through the methods of the relevant science.

## Epistemic rule

Every claim should be kept in one of four categories:

- established mathematical or scientific fact;
- reproducible observation inside the chosen decoding procedure;
- interpretation;
- hypothesis to be tested.

Historical source documents produced during earlier AI-assisted exploration are not treated as authoritative. The active English repository contains the realigned theory, not every legacy claim.
