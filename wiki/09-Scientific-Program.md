# Scientific Program

The key question is not whether the kernel is suggestive. It is whether Pi Theory can make predictions that can fail.

## Minimum requirements

- freeze future decoding rules before inspection;
- quantify the actual search space;
- use random and mathematical controls;
- perform blind semantic evaluation;
- test direction and zero-related hypotheses prospectively;
- distinguish pi from e, sqrt(2), phi, and matched random sequences;
- connect the theory to independent physical measurements.

## Highest-value target

The most important result would be a quantitative prediction that:

1. depends non-trivially on pi;
2. was fixed before the relevant data were inspected;
3. differs from control constants;
4. maps to an independent observation;
5. can be falsified.

Without that step, Pi Theory remains speculative philosophy plus exploratory pattern analysis.
