# e, pi, and i

Pi Theory uses an auxiliary mathematical grammar:

```text
e  -> self-proportional continuous variation
pi -> circular measure and cyclic closure
i  -> algebraic rotation and phase
```

Euler's relation connects these structures analytically:

```text
e^(i theta) = cos(theta) + i sin(theta)
```

This is mathematically important, but it does not by itself imply a metaphysical causal hierarchy or derive matter.

A safer conceptual sequence is:

```text
change -> cyclic change -> phase within a cycle
```

Discrete cycles remain possible, so cyclicity should not be reduced to continuous exponential change.
