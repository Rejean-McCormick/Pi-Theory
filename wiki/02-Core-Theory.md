# Core Theory

The theory can be understood first without the decoded words:

```text
unity -> distinction -> cohesion -> differentiation <-> integration
      -> transition -> new scale
```

## Source

The source principle is characterized by unity, balance, symmetry, no privileged direction, return, and inexhaustibility.

The ideal circle is treated as a spatial expression of this principle, not as a literal pre-spatial object.

## First distinction

The hardest metaphysical question is why a perfectly balanced unity differentiates at all. The theory does not yet have a complete answer.

## Cohesion

After distinction, parts can be re-integrated without being erased. This is the role later associated with `M`.

## Differentiation and integration

Complex wholes require both specialization and coordination. Pi Theory treats this pair as a core dynamic rather than as opposing final states.

## Threshold and scale

A sufficiently transformed system may cross a threshold and enter a new regime. This is the abstract role of `B0UM -> SIZE`.

## Recursive organization

A new whole can become a component of a larger whole:

```text
U0 -> D1 -> A1 -> U1 -> D2 -> A2 -> U2 -> ...
```
