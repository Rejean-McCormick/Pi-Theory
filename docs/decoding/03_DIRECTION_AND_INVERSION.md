# Direction et inversion

## 1. Fait de départ

Le renversement de la fenêtre est une opération de découverte. Aucune propriété connue de π n'impose actuellement cette lecture à l'envers.

Il est donc interdit d'écrire :

> « π doit mathématiquement être lu à l'envers ».

La formulation correcte :

> **L'inversion a révélé le kernel dans l'exploration; sa signification éventuelle reste à expliquer.**

## 2. Pourquoi le problème est profond

Une expansion infinie n'a pas de dernier chiffre global à partir duquel on pourrait « lire π tout entier à l'envers ». Le renversement ne concerne donc qu'une fenêtre finie.

La théorie doit expliquer pourquoi cette fenêtre et cette orientation seraient pertinentes.

## 3. Hypothèse de détermination globale et retour

La v3.1 distingue deux idées.

### 3.1 Détermination globale

`π_exact` est entièrement déterminé comme objet mathématique, tandis qu'une représentation finie n'en donne qu'un fragment. Pi Theory transpose cela métaphysiquement : le principe originel peut être **plus englobant que chaque différenciation locale**. Il n'est pas nécessaire de dire qu'il « voit le futur »; la relation globale est simplement prioritaire sur sa résolution locale.

### 3.2 Retour

```text
manifestation : principe → déterminations locales
retour : déterminations locales → principe / structure globale
```

L'inversion pourrait être une signature de ce second mouvement. La lecture par une conscience tardive est un cas particulier de ce retour, mais l'hypothèse v3.1 est plus générale : **la structure elle-même peut comporter procession et réintégration.**

## 4. Double lecture locale de B0UM

La région originale associée à B0UM est, avant inversion :

```text
83279502
```

et après inversion :

```text
20597238
```

La lecture inversée produit `B0UM`.

Dans le sens direct, la fin locale contient `0 → 2`; avec `2→B`, cela permet l'hypothèse secondaire :

```text
0 → B
```

et phonétiquement `B` peut évoquer *be / être*.

Ce point est intéressant parce qu'il donne :

```text
sens direct : motif de passage 0 → B
sens inversé : forme linguistique B0UM
```

Mais cette observation a été faite après découverte et doit donc devenir une **prédiction pour d'autres régions**, pas une preuve rétrospective.

## 5. Premier zéro et charnière de cycle

Dans la fenêtre canonique `314159265358979323846264338327950288`, le premier `0` apparaît à la position 33 en comptant le `3` initial. C'est le même zéro qui intervient dans `B0UM`.

Hypothèse v3.1 : ce zéro pourrait fonctionner comme un **marqueur de remise à zéro relative / transition de cycle**. Cette proposition ne suit pas des mathématiques de π; elle est née de l'interprétation et doit donc être testée ailleurs.

## 6. Retour non identique

L'inversion n'implique pas nécessairement un retour parfait. On introduit provisoirement :

```text
cycle n → retour → résidu ε_n → cycle n+1
```

Le résidu représente une différence conservée après réintégration. Si cette idée est correcte, l'inversion ne ramènerait pas à une copie exacte de l'origine, mais participerait à un **retour sans répétition**, compatible avec l'ouverture d'une nouvelle échelle.

## 7. Test directionnel proposé

Avant d'analyser de nouvelles fenêtres, définir :

- quelles propriétés sont attendues dans le sens direct;
- quelles propriétés sont attendues dans le sens inversé;
- une métrique de cohérence indépendante;
- des contrôles sur d'autres constantes et chaînes aléatoires.

Hypothèse testable :

> les relations ontologiques élémentaires seraient davantage visibles dans l'ordre direct, tandis que certaines cristallisations linguistiques seraient davantage visibles dans l'ordre inversé.

Cette hypothèse doit pouvoir échouer.
