# Pi Theory - Start Here

This is the active English working core of Pi Theory v3.1.

## 1. What the project is

Pi Theory begins from the mathematics of the ideal Euclidean circle, not from the digit decoding.

The core relation is:

```text
pi = C / d
```

where `C` is circumference and `d` is diameter.

The circle provides a precise conjunction of rotational symmetry, equal radii, no privileged angular direction, closure, and scale invariance of the ratio `C/d`.

Pi is an exact irrational number. Its value is complete as a mathematical object, while any positional expansion of it continues without termination or periodic repetition.

Pi Theory asks whether this relation between exactness, closure, measure, and inexhaustible representation can support a deeper structural model.

## 2. Core speculative hypothesis

The theory proposes a recurring architecture:

```text
unity
-> distinction
-> cohesion
-> differentiation
<-> integration
-> threshold transition
-> new scale
-> renewed cycle
```

The strongest current form does not claim that pi literally computes the universe. It asks whether mathematical structure may participate in the generative grammar of reality rather than merely describe finished outcomes.

## 3. The decoding kernel

A finite early window of the decimal expansion was explored with a human-designed transformation pipeline. The stabilized output is:

```text
M -> BIEN -> GIHECEF -> JNON -> B0UM -> SIZE
```

The current functional reading is:

```text
M       = cohesion / reintegration
BIEN    = orientation toward non-capturing coherence
GIHECEF = differentiation / transformation
JNON    = integration / assembly
B0UM    = threshold transition / creation event
SIZE    = magnitude / scale regime
```

The decoding was exploratory. The rules were stabilized after discovery. It is therefore reproducible ex post, not confirmatory evidence by itself.

## 4. Recursive return

A newer hypothesis concerns direction and return. The exact mathematical structure is globally determined, while manifestation, if such a relation exists, may be locally resolved.

The working model is:

```text
source -> differentiation -> manifestation -> reintegration
       -> residual difference -> transition -> new scale -> new cycle
```

Return is not assumed to erase difference. A later whole may preserve prior distinctions while reorganizing them into a higher-order coherence.

## 5. Cosmological reading

`B0UM -> SIZE` is treated as a potentially important correspondence:

```text
initial transition -> scale / metric / spatial regime
```

The Big Bang is a candidate cosmological instantiation of `B0UM`, not yet an identity established by evidence. `SIZE` is interpreted more generally as the emergence or transformation of measurable scale.

## 6. Matter, life, consciousness, and language

The long-range architecture is:

```text
mathematical structure
-> physical stabilization
-> matter as inherited constraint / history
-> self-organizing life
-> cognition
-> consciousness
-> symbolic representation
-> retrospective recognition of structure
```

The language hypothesis is not that French or any human language literally existed in pi before humans. It is that mathematics, nature, cognition, and language may all be constrained by deeper recurring structures.

## 7. What would make this scientific

The next stage must produce tests that can fail. In particular:

- freeze future decoding rules before inspecting new targets;
- compare pi with e, sqrt(2), phi, and randomized controls;
- quantify degrees of freedom in segmentation, reversal, mapping, and phonetic interpretation;
- use blind raters for semantic recoverability;
- develop a pi-specific quantitative prediction connected to independent physical data.
